# Python Basics Lab

Hey there! 👋

This repository contains simple Python programs that answer basic Python questions. Perfect for beginners learning the fundamentals!

## What's Inside?

These are straightforward programs covering:
- Conditional statements (if/else)
- Loops (for and while)
- Basic input/output
- Simple calculations

Each file is self-contained and focuses on one concept, making it easy to learn and practice.

## How to Use

Just run any Python file to see it in action:

```bash
python q1_positive_negative_zero.py
```

## Topics Covered

- Checking positive/negative/zero numbers
- Greeting messages and variables
- Comparing numbers
- Even/odd detection
- Divisibility checks
- Age/teenager validation
- Number sequences and loops
- Sum calculations
- Multiplication tables
- Password validation
- Leap year checker

Happy coding! 🐍
